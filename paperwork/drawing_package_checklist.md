# Drawing Package Release Checklist

What a released switchgear drawing package contains, and the checks
run before it goes out. Tick each item when it is true of the
package in hand, not when it is planned to be true later.

## Contents

* \[x] One-line diagram (D-201), current revision
* \[x] Lineup elevation (D-202), current revision
* \[ ] Control schematics for each breaker (open/close circuits, trip
coils, spring charging motor, auxiliary contacts)
* \[ ] Bill of materials covering every section, breaker, and device
shown on the drawings
* \[ ] General notes sheet (or notes block) with the standards the
gear is built and tested to

## Consistency checks

* \[x]Revision letter in every title block matches the revision log
* \[ ] Every ECO behind the current revisions is approved and filed
* \[ ] Ratings on the drawings (bus, breakers, transformer) match the
bill of materials line by line
* \[ ] Device numbers on the schematics match the one-line diagram
(52-M, FDR-01, FDR-02, and so on)
* \[x] Sheet count in every title block matches the real package
("SHEET: 1 OF 2" means there are exactly two sheets)
* \[x] No redline markup is left unincorporated or unexplained

## Files and records

* \[x] Native CAD files (DWG or DXF) saved under the drawing numbers
* \[x] A PDF of every sheet at the released revision
* \[ ] Files checked into the PLM system at the released revision,
lifecycle state set to Released
* \[x] Superseded revisions still retrievable (released history is
never deleted)
