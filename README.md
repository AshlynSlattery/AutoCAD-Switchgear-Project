# AutoCAD Switchgear Drawing Package

A practice drawing package for medium-voltage switchgear: a one-line
diagram, a lineup elevation, the redline and revision cycle between
them, and the engineering change paperwork that makes a revision
official. The point is the full working loop a project engineer runs
on real orders: draw, get marked up, revise, run the change through
an ECO, release a package that agrees with itself.

The starting package holds one controlled drawing. D-201, the
one-line diagram of a 15 kV class lineup (utility source, main
breaker, 2000 A bus, two feeders, a 1500 kVA transformer, and
loads), is complete at Revision A, with a redline markup waiting to
be worked into Revision B.

## How this project started

This project came out of an audit of job descriptions for engineering
roles applied to in fall 2026, compared against a resume. The
switchgear project engineer roles asked for AutoCAD proficiency and
3D design experience, plus working vocabulary that does not show on
a transcript: drawing revisions, engineering change orders, PLM
systems such as Windchill, ERP systems such as SAP, and the ANSI,
IEEE, and NEC standards switchgear is built to. This project builds
that vocabulary by doing the work, not by reading about it.

The starting scaffold was generated with AI assistance and handed
over on October 17, 2026, in the opening commits of this repository.
Complete in the scaffold: the D-201 Revision A one-line diagram (a
real DXF, generated by the script in scripts/ and checked), the
redline markup for Revision B, a completed ECO form as a worked
example plus a blank template, the revision log with Revision A
entered, the package release checklist, and the standards crib
sheet. Hers to do, listed in TASKS.md: the lineup elevation drawing,
Revision B of the one-line, the ECO and revision log entries for
that change, and the Windchill and SAP write-up. Everything
committed after the opening commits is her work.

## Setup

No code environment is required for the main work.

- Install LibreCAD (free, from librecad.org) or start an AutoCAD
  trial. Both open the DXF files in drawings/. LibreCAD saves DXF
  natively, which keeps the file format consistent with the
  scaffold.
- Open drawings/D-201_one-line_revA.dxf and compare it with
  drawings/D-201_one-line_preview.png to see the sheet whole before
  zooming into details.
- Optional: the generator script needs Python 3 with ezdxf and
  matplotlib (`pip install ezdxf matplotlib`), then
  `python scripts/generate_one_line.py` rebuilds the Rev A drawing
  and its preview. Useful if you want to see how the starter drawing
  was constructed, or to check your own files the same way
  (ezdxf reads any DXF back and audits it for errors).

## Layout

- `drawings/` - D-201 Revision A (DXF plus PNG preview) and
  MARKUP.md, the redline to work into Revision B. Your D-202
  elevation and the Revision B file go here too.
- `paperwork/` - the ECO worked example, the blank ECO template,
  the revision log, and the drawing package release checklist.
- `reference/` - the standards crib sheet, and the file where the
  Windchill and SAP write-up goes.
- `scripts/` - the generator that produced the starter drawing.
- `TASKS.md` - the four pieces of work that are yours, each with a
  checklist and a statement of what done looks like.
